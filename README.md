# 週次勤務時間 集計システム

手書き出勤簿の写真・スキャンをAIで読み取り、丸め設定に基づいて日曜〜土曜の週単位で
勤務時間を集計し、週28時間(留学生の資格外活動上限)を超えていないかチェックする
社内ツールです。PDF出力(印刷)にも対応しています。

## 構成

- `server.js` — Express製の軽量サーバー。静的ファイルの配信と、`/api/ocr` で
  Anthropic API(画像認識)への橋渡しを行います。
- `public/index.html` / `public/app.jsx` — フロントエンド。ビルド不要で、
  ブラウザ上でBabelがその場でJSXを変換します。

APIキーはサーバー側の環境変数としてのみ保持され、ブラウザには一切送信されません。
以前アーティファクト単体で試した際に「Failed to fetch」になっていたのは、ブラウザから
直接 `api.anthropic.com` を呼ぼうとして通信環境に阻まれていたためです。この構成では
サーバー(Render等)からAnthropicへ通信するため、その問題を回避できます。

## ローカルでの動作確認

```bash
npm install
cp .env.example .env
# .env の ANTHROPIC_API_KEY に実際のキーを設定
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

## Renderへのデプロイ手順

1. このフォルダ一式をGitHubリポジトリにpushする
   (以前の `haken-roster-app` と同じ要領です)
2. Renderのダッシュボードで「New +」→「Web Service」を選択し、
   このリポジトリを連携する
3. 設定項目:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
4. 「Environment」タブで環境変数を追加:
   - `ANTHROPIC_API_KEY` = 実際のAPIキー
5. デプロイが完了すると発行されるURLでアクセスできます

## 使い方

1. 「原本(出勤簿の写真・スキャン)」から画像・PDFを添付
2. サムネイルを選び、「この原本を読み込んで自動反映」を押すとAIが読み取り、
   氏名・就業先・各日の出社/退社/休憩時刻を表に自動入力(黄色=未確認)
3. 黄色いマスは原本と見比べて、クリックまたは修正して確認済みにする
4. 会社ごとの締め日・丸めルールは「会社・締め日」パネルで設定・保存できる
5. 「PDF出力プレビュー」で仕上がりを確認し、「PDFとして出力」で印刷・保存
